Tentang Saya

Saya merupakan lulusan Teknik Informatika dari Universitas Suryakancana. Saya memiliki ketertarikan dalam pengembangan website, sistem informasi, database, pengolahan data, dan implementasi Data Warehouse.

Sebelum menempuh pendidikan Teknik Informatika, saya menyelesaikan pendidikan Akuntansi dan Keuangan Lembaga di SMK Plus Ashabulyamin. Latar belakang ini membantu saya memahami proses bisnis, administrasi keuangan, pencatatan transaksi, dan pengelolaan data.

Saya telah mengembangkan proyek sistem informasi dan analisis data, termasuk aplikasi Bank Mini Sekolah serta implementasi Data Warehouse untuk analisis persebaran dapur MBG di Kabupaten Cianjur.

  • Memiliki pengalaman mengembangkan aplikasi web berbasis PHP, Laravel, dan MySQL.
  • Memahami perancangan sistem, database, alur bisnis, dan manajemen data.
  • Memiliki dasar akuntansi, administrasi keuangan, pencatatan transaksi, dan pelaporan keuangan.
